HOST IDENTITY CHANGED

A changed host requires deliberate re-pairing.

If a host is reinstalled or another machine appears at the same address, Jochona blocks the connection rather than silently trusting the replacement.

Built around ownership, not lock-in.

Five choices govern the client, from the first pairing screen to a stream already in motion.

  • Excellent defaults, visible control.

    Sensible settings arrive ready. Every one remains reachable and changeable.

  • Controller-first, not controller-only.

    Use a gamepad from the couch, or a keyboard and mouse at the desk.

  • Capability-driven.

    The interface responds to what your host can do, not a guessed version string.

  • Recover rather than fail.

    Diagnostics name the likely problem and point toward the next useful action.

  • Local ownership.

    No account and no cloud dependency. Your secrets remain in your OS vault.
